## Navigation Structure

### Шапка (Header)
| Элемент | Описание |
|---------|---------|
| **RADAR** | Логотип / название приложения |
| **[Р]** | Кнопка перехода в Профиль |

### Нижняя панель (5 вкладок)
| Вкладка | Иконка | Назначение |
|--------|--------|------------|
| **RADAR** | радар-иконка | Главный экран (контакты, быстрые действия) |
| **QR** | QR-иконка | QR-обмен визитками |
| **Встречи** | календарь | Список встреч, планирование |
| **Контакты** | люди | Стратегические связи |
| **Навигатор** | навигатор | Чеклист "Правило первого контакта" |

### Профиль (экран, открывается по [Р])
| Секция | Содержимое |
|--------|-----------|
| Аватар + Имя | Фото, имя пользователя |
| Баланс звёзд | ⭐ X звёзд, заработано / потрачено |
| Подписка | Free / Premium / Trial, управление |
| Реферальная программа | Приглашённые, прогресс к Premium |
| Настройки | Другое |

## Route Mapping (React Router)

| Путь | Компонент | Описание |
|------|-----------|---------|
| `/` | `MainScreen` | Главный экран (RADAR) |
| `/contacts` | `ContactsScreen` | Контакты / Стратегические связи |
| `/contacts/:id` | `ContactDossier` | Досье контакта |
| `/card/:contactId` | `CardDetail` | Детали визитки |
| `/profile` | `ProfileScreen` | Профиль пользователя |
| `/navigator` | `NavigatorScreen` | Навигатор |
| `/qr-exchange` | `QRExchange` | QR-обмен |
| `/referral` | `ReferralScreen` | Звёзды RADAR (реферальная программа) |
| `/meeting/:id` | `MeetingFlow` | Поток встречи |
| `/network-graph` | `NetworkGraph` | Сетевой граф |
| `/scan-confirm/:userId` | `ScanConfirm` | Подтверждение добавления контакта |

## Data Models (Frontend)

### User
```typescript
interface User {
  id: number;
  username: string;
  firstName: string;
  lastName?: string;
  photoUrl?: string;
  balance: number;
  subscription: {
    plan: 'free' | 'premium';
    isActive: boolean;
    trialEnd?: string;
    expiresAt?: string;
  };
}
```

### Contact
```typescript
interface Contact {
  id: number;
  contactId: string;
  businessName: string;
  personalData: string;       // JSON: { fullName, phone, email, ... }
  resources: string;           // JSON: { website, telegram, ... }
  circle: 'support' | 'productivity' | 'development';
  archetype?: string;
  aiSuggestedRole?: string;
  privateMeta: object;          // ОИС теги (encrypted)
  referralSource?: 'card_link' | 'qr_exchange' | 'manual';
}
```

## Tech Stack

| Layer | Technology |
|-------|-----------|
| Frontend | React 18 + TypeScript + Vite |
| Routing | React Router v6 |
| State | React hooks (useState/useContext) |
| HTTP | Axios |
| Telegram | telegram-web-app.js SDK |
| Backend | NestJS + Prisma |
| Database | PostgreSQL |
| Auth | JWT + Telegram initData |
