### Компоненты Backend:

| Компонент | Описание |
|-----------|----------|
| **Controllers** | Обработка HTTP запросов, валидация DTO |
| **Services** | Бизнес-логика, координация между репозиториями |
| **Prisma Service** | Работа с базой данных, миграции |
| **Telegram Service** | Отправка уведомлений через бота |
| **JWT Guard** | Защита endpoints, валидация токенов |
| **Referral Service** | Логика реферальной программы, начисление баллов |
